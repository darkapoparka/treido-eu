At inspection: **556 enumerated files**, **409 TS/TSX/CSS/JS/MJS source files**; web `src` contains **230 TS/TSX modules**, **83 explicit client entries**, **14 server-only imports**, **57 page routes**, **four reference route handlers** and one root layout. **116 test/spec files** include the separate reference suite. Explicit client-entry count does not measure the final client bundle. Provider-wrapped server children are not automatically client-rendered. File length uses newline splitting, so a trailing newline can add one to the reported size; large fixtures are not all architectural defects.

The app is a substantial reference reconstruction with useful tests and protective boundaries. The highest-priority gap is real marketplace authority/persistence, not wholesale visual replacement. Preserve tested models/journeys, isolate reference fixtures, introduce narrow contracts and replace one use case at a time.
