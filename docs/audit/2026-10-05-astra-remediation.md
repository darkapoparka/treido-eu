**Dependency audit.** The current audit still flags node-forge 1.4.0 ([GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv)) and braces 3.0.3 ([GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)). The audited registry response supplies no patched version for either. Neither vulnerability is treated as fixed by the decoder change, declaration snapshot, test success or an unproven reachability assumption. A qualified upstream or independently reviewed replacement/remediation is still required; the CI audit gate stays intact.

**Abandoned billing change.** A ready Stripe billing-portal plan-change session can remain locally pending after the application stops displaying its URL. This still blocks subsequent conflicting money operations. The current portal API/installed SDK provides creation, but no supported session cancellation/expiration or state lookup usable by this implementation. A local deadline or unchanged subscription price does not establish that an already opened provider flow cannot still act. The safe repair requires provider-backed closure/supersession or a reviewed redesign, with a race test against confirmation of the old flow. T71 does not release the uniqueness guard, guess a timeout or pretend the defect is resolved.

**Real launch acceptance.** The original handoff still identifies invitation email, private end-user message attachments, approved application/provider bindings and signed-in buyer/seller/operator journeys as incomplete or unqualified. Legitimate supply, operational alert ownership and the remaining financial/shipping/retention approvals must be checked against their original task acceptance. T71 did not send real mail, enable payments, change production policy, seed approvals or deploy a service.

**Concurrent Studio work.** The active seller/admin-preview changes and their new rich-text test belong to another writer. They are preserved locally and excluded from this publication. Their current lint defects and ongoing source changes are not silently fixed, discarded or represented as reviewed T71 work.
