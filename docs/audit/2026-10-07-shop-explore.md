## Why the presentation drifted

1. [Explore](../../app/apps/web/src/features/discovery/explore.tsx) retains the original replay body but branches to [PublicExplore](../../app/apps/web/src/features/discovery/public-explore.tsx) for genuine supply. Reusing its outer shell, tiles and shelves did not preserve the whole composition: the public branch explicitly omits editorial/Minis and assembles different category chrome.
2. [Calibrated category CSS](../../app/apps/web/src/features/discovery/explore.module.css) still targets literal reference identities such as `data-category="Beauty"`. Genuine categories use canonical identities such as `cat:beauty-care`. That specialization is not selected by the genuine route. [Public CSS](../../app/apps/web/src/features/discovery/buyer-surface.css) instead supplies custom rail margins/padding/pill state. A matching class name alone cannot reproduce the reference cascade. This is a source-code finding; no fresh populated Beauty comparison is claimed.
3. [The public projection](../../app/apps/web/src/features/discovery/explore-model.ts) supplies category photos only from the current eligible results and repeats a six-color array by index. Thin seed supply therefore exposes generic placeholders across most of the taxonomy. Missing qualified artwork is a separate gap from missing category data.
4. Focused public tests verify routes, scope, canonical identity and failure handling. The retained reference Explore suites exercise replay/source fixtures. Passing those independently does not compare the real-data composition against Shop. The October 6 task receipt also records that the first navigation repair added three chrome rows and incorrectly documented them before the owner caught the mismatch.

The emulator blocker does not explain or excuse those frontend choices: usable retained source material was already present. The root cause is an incomplete presentation connection and insufficient source comparison during acceptance, not an inability to enumerate categories or a lack of reference images.
